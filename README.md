# Foto Space — Releases

Installer & update feed (electron-updater) untuk aplikasi Foto Space.

- **Windows**: `foto-space-<version>-setup.exe`
- **Linux**: `foto-space-<version>.AppImage`
- **Feed**: `latest.yml` (Windows), `latest-linux.yml` (Linux)

Aplikasi memerlukan lisensi aktif untuk digunakan.
